# Jarvis HOME — Smart Ambient Display

# Overview

Jarvis HOME is an ultra-HD, mobile-responsive smart display web application built with a stunning pine-forest glassmorphic aesthetic, golden typography, a hidden-until-playing Now Playing music card, an interactive Settings control center, a Custom CSS Widget Studio, and a cozy English voice assistant powered by Web Speech synthesis.

# Key Features

1. Immersive Pine-Forest & Glassmorphism Design

High-contrast ambient forest backdrop with configurable theme presets (Pine Forest, Misty Evergreen, Golden Canopy, Midnight Ridge).

Premium frosted glass cards (backdrop-blur) with warm golden accents (#FDE047) and tall condensed Jarvis HOME typography.

2. Hidden-Until-Playing Now Playing Music Card

Completely hidden by default when no audio is playing to maximize screen space.

Smoothly animates into view the moment music starts (via voice command, Spotify launcher, or widget).

Interactive playback controls, album art visualizer, and ambient synth audio generator.

3. Smart Timetable & Time Engine

Live date & time display with automatic 12-hour / 24-hour toggle and auto-tomorrow preview after school hours.

Quick-switch day buttons (AUTO, ПН, ВТ, СР, ЧТ, ПТ) and full row-by-row timetable editor.

4. Cozy English Voice Assistant

Uses the Google US English cozy voice model with softened pitch and slow cadence (rate: 0.88, pitch: 0.88) for soothing voice feedback.

Number-free schedule readout (e.g., "First period — English, second period — Mathematics").

Wake-word listener indicator ("LISTENING FOR WAKE WORD...").

5. 🎨 Custom CSS Widget Studio

Write custom HTML and CSS directly inside the Settings control center.

Instantiate your bespoke widgets and pin them to any of the 3 home screen widget slots.

6. Fully Mobile Responsive

Perfectly optimized font sizes, touch targets, and flex/grid layouts for mobile phones, tablets, and desktop displays.

# Getting Started

Download or clone index.html.

Open the file in any modern web browser (Google Chrome, Safari, Firefox, Edge).

Click SETTINGS in the top right to customize your name, timetable, wallpaper theme, widgets, or write your own custom CSS components!
